# TeachYOLO — Локальная веб-студия разметки и обучения YOLO26

**TeachYOLO** — это автономное, быстрое и современное веб-приложение для полного цикла работы с нейросетями семейства **YOLO26** (от загрузки сырых видео и фото до разметки, сборки датасета, обучения и экспорта весов).

---

## 🌟 Основные возможности
1. **Загрузка данных**:
   * Поддержка фото (`.jpg`, `.png`, `.webp`, `.bmp`).
   * Поддержка видео (`.mp4`, `.avi`, `.mov`, `.mkv`) с автоматической раскадровкой (нарезка каждого $N$-го кадра через OpenCV).
2. **Интерактивная разметка (HTML5 Canvas + Fabric.js)**:
   * Удобный визуальный редактор Bounding Box (рамки объектов).
   * Переключение между кадрами с клавиатуры (стрелки `←` / `→` или клавиши `A` / `D`).
   * Зумирование, панорамирование (пробел + мышь), автосохранение разметки.
3. **Генератор датасетов**:
   * Автоматическая нормализация координат (YOLO формат).
   * Строгая последовательная переиндексация классов с нуля (`0, 1, ..., N-1`), исключающая ошибки фреймворка.
   * Разделение на обучающую (Train) и валидационную (Val) выборки.
4. **Обучение нейросетей YOLO26**:
   * Поддержка новейших моделей: `yolo26n.pt`, `yolo26s.pt`, `yolo26m.pt`, `yolo26l.pt`, `yolo26x.pt`, `yoloe-26s.pt`, `yoloe-26m.pt`.
   * Изоляция процессов (Multiprocessing) — обучение не блокирует интерфейс.
   * Живая трансляция логов и прогресса обучения в терминал браузера через WebSockets.
5. **Экспорт и шеринг**:
   * Экспорт обученных моделей в форматы: `ONNX`, `TensorRT (.engine)`, `TorchScript`, `OpenVINO`, `CoreML`.
   * **1-Click обмен проектами**: возможность скачать проект как ZIP-архив и импортировать его на любом другом компьютере.

## 🚀 Быстрый старт (Установка и запуск)

Приложение полностью автономно и готово к работе сразу после распаковки или клонирования репозитория. Никаких сложных ручных настроек не требуется!

### 🐧 Linux / macOS
1. Откройте терминал в папке с проектом.
2. Сделайте скрипты исполняемыми и запустите установку:
   ```bash
   chmod +x setup.sh run.sh
   ./setup.sh
   ```
   *(Скрипт сам создаст виртуальное окружение `.venv` и установит все библиотеки).*
3. Запустите веб-студию:
   ```bash
   ./run.sh
   ```
   *Сервер поднимется на **http://localhost:8000**, и браузер откроется автоматически.*

---

### 🪟 Windows
1. Убедитесь, что на компьютере установлен **Python 3.10** (или новее) с официального сайта [python.org](https://www.python.org/downloads/) (при установке обязательно поставьте галочку **"Add Python to PATH"**).
2. Дважды кликните по файлу **`setup.bat`** (или запустите его из командной строки).
   *(Скрипт создаст папку `.venv` и скачает необходимые зависимости).*
3. Для старта работы дважды кликните по файлу **`run.bat`**.
   *Откроется консольное окно сервера, а в браузере запустится интерфейс на **http://localhost:8000**.*

## 📦 Как делиться проектами с коллегами
Вы можете передавать свои наработки, размеченные датасеты и обученные нейросети другим людям в один клик:
1. **Чтобы поделиться**: На главной странице в карточке вашего проекта нажмите кнопку **`[ 📦 ZIP ]`**. Браузер скачает архив проекта (с фотографиями, разметкой и классами).
2. **Чтобы открыть у себя**: На новом компьютере или у коллеги нажмите в шапке панели проектов кнопку **`[ 📥 Импорт ZIP ]`** и выберите полученный архив.
3. Проект мгновенно появится в списке! При первом запуске обучения система автоматически адаптирует пути под новый компьютер.

## 💡 Важные рекомендации по обучению
* **Минимум 50 изображений**: Для того чтобы модель уверенно находила объекты на динамичном видео, рекомендуется разметить не менее 50 разнообразных кадров (с разных ракурсов, при разном освещении).
* **Минимум 50–100 эпох**: 10 эпох недостаточно для сходимости YOLO (модель будет выдавать `no detection` при стандартном пороге уверенности). Устанавливайте в настройках минимум 50–100 эпох.
* **Аппаратное ускорение**: Если в системе установлена видеокарта NVIDIA с драйверами CUDA, выберите в настройках обучения устройство **`GPU 0 (CUDA)`** — скорость обучения вырастет в десятки раз по сравнению с CPU!
